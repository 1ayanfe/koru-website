# KORU Health Website

This is a simple beginner-level website project made with HTML, CSS and JavaScript.

## Pages
- `index.html` - Home page
- `about.html` - About page
- `services.html` - Services page
- `contact.html` - Contact form page

## Folders
- `css` contains the stylesheet.
- `js` contains the JavaScript file.
- `images` contains the KORU Health logo supplied for this project.

## How to open the website
1. Extract the project ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a web browser. Live Server is optional.

## Features used
- HTML headings, paragraphs, links, images, forms and labels.
- CSS colours, spacing, borders, Flexbox and Grid.
- Media queries for smaller screens.
- JavaScript for the footer year and contact form validation.

The contact form is only a demonstration. It checks the fields but does not send or save messages.

## Important
KORU Health is an educational student project. Its content is general information and is not medical advice.
